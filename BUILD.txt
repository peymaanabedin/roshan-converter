ROSHAN CONVERTER 2.0.0 — REBUILDING THE WINDOWS X64 APP
=====================================================
Programming and development by Peyman Abedinpour
peymaanabedinpour.ir

The native interface, queue, metadata handling, encoding orchestration, file
safety and offline payload management are written in Rust. A C++ bridge uses
libheif/x265/libde265/LittleCMS for HEIC and managed color. The other image
codecs are Rust libraries. FFmpeg and ffprobe are independent static workers,
compressed into the EXE at build time and extracted privately at runtime.
No runtime compiler, codec download, .NET, WebView or separate FFmpeg is needed.

BUILD TOOLS (DEVELOPERS ONLY)
Build host: Linux x86_64, Python 3.12+, C/C++ compiler and GNU Make.
Rust 1.99.1 (2026-10-13), target x86_64-pc-windows-gnullvm.
LLVM-MinGW 20261006 UCRT / Clang 23.1.3, CMake 4.1.2 and NASM.
Rebuilding the video workers also needs Meson, Ninja, pkg-config, Autoconf,
Automake, Libtool and ordinary Unix shell utilities.
Build tools are not included as application runtime dependencies. Install or
unpack them before an offline rebuild; all library/codec sources are included.

BUILD THE WINDOWS APPLICATION
From this source directory, with the build tools on PATH:
  python3 scripts/assemble_notices.py
  python3 scripts/build_release.py --llvm-mingw /absolute/path/to/llvm-mingw

The script builds the native image libraries from the included archives. It
uses the included Windows video workers; if they are absent, it builds them
from the included sources. Cargo uses --release --locked --offline and the
included vendor/ directory. No build step downloads codec or Rust libraries.
The gnullvm target uses LLVM's C++ runtime consistently, with static linkage.

Results:
  release/Roshan-HEIC.exe
  release/windows-imports.json
The historical EXE filename is retained; the app displays Roshan Converter.

To reuse already built image libraries or video workers:
  python3 scripts/build_release.py --llvm-mingw /path/to/llvm-mingw \
    --native-prefix /path/to/native/windows \
    --video-prefix /path/to/video-native/windows
An optional CARGO_TARGET_DIR selects a fresh compilation directory; this is
useful when changing a pre-existing checkout from registry to vendored sources.

REBUILD THE VIDEO WORKERS FROM SOURCE
  python3 video-native/build_video.py --target windows \
    --llvm-mingw /path/to/llvm-mingw --jobs 2
See video-native/README.md for all flags, source provenance and reproducibility.
The payload build enables GPL version 3, never nonfree, and disables networking.
Only file and pipe protocols are available. The application also restricts
input protocols and uses absolute file paths, without a command shell.

LINUX VALIDATION
  python3 native-build/build_native.py --target linux --output native-prefix
  python3 video-native/build_video.py --target linux --jobs 2
  ROSHAN_NATIVE_DIR="$PWD/native-prefix/linux" cargo test --locked --offline
  ROSHAN_NATIVE_DIR="$PWD/native-prefix/linux" cargo build --release --locked --offline
  target/release/Roshan-HEIC --convert --to png --output /path/to/new-output input.heic
  target/release/Roshan-HEIC --convert --to webm --output /path/to/new-output input.mp4
The Linux executable is a developer command-line build, not the Windows UI.
ROSHAN_FFMPEG_DIR can select an alternate directory containing ffmpeg/ffprobe.

QUALITY AND EXECUTION EVIDENCE
Read verification/README.txt and the v2 JSON reports. Tests run the actual
Windows PE executable under an isolated Wine 11 environment; this is not a
claim of testing on a physical Windows installation. The reports distinguish
codec tests, integrated app tests and GUI harness checks. Final hashes identify
which exact executable was tested. Public photo fixtures remain URLs/hashes;
they are not redistributed in this source archive. Synthetic test inputs are
reproducible from the supplied scripts.

You can modify the extracted dependency sources and relink the application
using the same build scripts. Archive hashes verify the pristine supplied
archives. See the native/video build READMEs before rebuilding changed sources.
